# Numbers, Data and Values

Numbers are semantic hero candidates, not automatically ordinary words.

Support:

Compositions:
Giant Number, Number + Context, Inline Number Hero, Count Up, Percentage Hero, Currency Hero, Year/Date Hero, Multiplier Hero.

Examples:

or:

sales increased by
       47%
this year

Currency/value should remain one visual unit where appropriate. Count-up is timeline-driven and ends on the real value.
