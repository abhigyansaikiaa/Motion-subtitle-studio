# Antigravity Reference Rules

Use this pack as DESIGN DIRECTION, not as a cloning source.

DO:
- create specific recognizable compositions
- combine hierarchy + geometry + typography + depth + motion
- preserve word-level timing
- make animation timeline-driven
- keep preview/export visually consistent
- use video-relative coordinates
- support 9:16, 16:9, 1:1, and 4:5
- preserve the existing working caption/render pipeline

DO NOT:
- reduce the system to generic Karaoke/Typewriter/Bold/Dynamic presets
- copy another product's branding, UI, assets, or exact layouts
- break existing animations
- place captions in browser black margins
- fake behind-subject effects with z-index
- replace server rendering with browser video processing
- silently downgrade complex animation during export
